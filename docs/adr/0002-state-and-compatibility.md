# ADR-0002：键码、所有权与兼容语义

状态：采用。日期：2026-10-08。

核心物理键用 HID page/usage，按设备连接 generation 区分来源。单线程引擎与注入单调时钟；每次按下绑定当时的配置快照，松开不重新匹配。

输出 owner set 使两个来源映射同一键时，第一来源松开不提前释放另一来源。这里有意改善上游普通键按 usage 去重的行为，用 KeyWeave 独立 golden 验证，不能修改上游 oracle。

配置 AST 保留 metadata，功能字段严格编译；未知或当前未实现 action/condition 禁用整条规则。语法/结构错误拒绝整个快照。缺少上下文时 if/unless 均不匹配，不能对 Unknown 取反。

阶段顺序固定，支持的兼容子集随实现增加。导入和 validate 不执行 shell/JavaScript，不自动激活有损转换。所有时间测试使用整数纳秒；上游 Mach 编码只在拥有实际单位证据时转换，第一批无定时案例只比较键事件语义，不宣称已转换 Mach 时间。
